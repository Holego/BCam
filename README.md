
# Background Camera  — приложение для записи в фоновом режиме

## Что делает
Одна круглая кнопка по центру экрана: тап — старт записи видео, повторный тап — стоп.
Запись идёт через foreground-сервис, поэтому продолжается, даже если свернуть приложение
или заблокировать экран. Видео сохраняется в Movies/VideoRecorder через MediaStore.

## Файлы
- `app/build.gradle.kts.txt` — зависимости (переименуй в `build.gradle.kts` в проекте)
- `app/src/main/java/.../MainActivity.kt` — экран с кнопкой
- `app/src/main/java/.../RecordingService.kt` — foreground-сервис с логикой CameraX

## Как использовать
1. Создай новый пустой проект в Android Studio (Empty Activity, Kotlin, Compose).
2. Замени содержимое `build.gradle.kts` (Module: app) на файл из этого набора.
3. Замени `AndroidManifest.xml` на файл из этого набора (поправь package name, если у тебя другой).
4. Скопируй `MainActivity.kt` и `RecordingService.kt` в свой пакет.
5. Sync Gradle, собери и запусти на реальном устройстве (эмулятор плохо работает с камерой).

## Важные ограничения
- На Android 10+ нельзя обращаться к камере из полностью свёрнутого приложения без
  активного foreground-сервиса с типом `camera` — поэтому вся логика записи вынесена в сервис.
- Пока идёт запись, в шторке уведомлений будет постоянное уведомление — это требование
  системы, его нельзя скрыть, только можно кастомизировать текст/иконку.
- Если хочешь остановить запись именно нажатием той же кнопки после сворачивания
  приложения — понадобится либо виджет на главном экране, либо кнопка действия
  прямо в уведомлении (`addAction()` в NotificationCompat.Builder).
